# Security

Please report security problems privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Do not open a public issue.

Include what you found, how to reproduce it, and which version (`VERSION`) you used. I will reply as soon as I can.

T3 Tots tools are read-only by default and never read T3 secret or token files. If you find a case where they do, or where the install script could fetch something other than the published files, that is a security issue.
